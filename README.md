## Featured Project

### 🚀 Block-Synchronous Gradient Boosting
> *Supplemental code & results for the paper submitted to AutoML 2026*

A novel parallelisation strategy for Gradient Boosted Machines that exploits **across-iteration parallelism** on multi-core CPUs. Instead of the standard sequential tree-building loop, trees within a "block" are trained in parallel, with learning-rate scaling to compensate for the increased effective step size.

- 📌 &nbsp;Benchmarked on **Santander**, **Covertype**, **UCI Adult**, and **IEEE-CIS** datasets
- ⚙️ &nbsp;All experiments run on **Kaggle free tier** (~60 CPU-hours total) — no GPU required
- 📄 &nbsp;Includes full experiment scripts, raw CSV results, and figure-generation code
- ✅ &nbsp;Fully reproducible with fixed random seeds

[![View Repository](https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/BaibhavKundu2005/Block-Parallel-GBM)
