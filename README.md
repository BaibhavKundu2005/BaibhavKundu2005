## Experience

### 🔭 Quantum-ML Research Intern — C-DAC, Noida *(May – Jul 2026)*
Built a PyTorch + PennyLane pipeline for 10-day multi-output weather forecasting across Indian cities, with leakage-free feature engineering. Designed a controlled study isolating the quantum parameter fraction (325-run grid + 150-run, 6-seed confirmatory stage, Wilcoxon tests with Holm correction) showing prediction error is uncorrelated with the quantum fraction while simulation cost scales near-linearly — evidence that reported "quantum advantage" is a bottleneck artifact, not a circuit effect. Authored 2 conference manuscripts.

## Featured Projects

### 🚀 Block-Synchronous Gradient Boosting
> *Accepted — WAML-HPC Workshop @ PPAM 2026 (Springer LNCS)*

A novel parallelisation strategy for Gradient Boosted Machines that exploits **across-iteration parallelism** on multi-core CPUs — fitting B trees per block against a shared residual with 1/B learning-rate scaling, parallelised via joblib's loky backend without modifying the base learner.

- 📌 &nbsp;+0.031 AUC over sequential boosting on Santander, 3.9x more trees in equal wall-clock
- ⚙️ &nbsp;Benchmarked across **4 datasets / 60+ CPU-hours** on the Kaggle free tier — no GPU required
- ✅ &nbsp;Fully reproducible with fixed random seeds

[![View Repository](https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/BaibhavKundu2005/Block-Parallel-GBM)

### 🛒 NowCart — ML & Retrieval
> *National Finalist — HackOn with Amazon 2026*

Turns a plain intent ("biryani for 4") into a cart: a bi-encoder + cross-encoder retrieval stack over a 9,534-SKU catalog, a cross-language alias table, and RapidFuzz typo fallback. Orchestrated as a 6-node LangGraph graph (intent → decompose → match → confidence → counterfactual) with a bounded replan loop so failures degrade gracefully instead of breaking the cart.

[![View Repository](https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Strizzyy/NowCart)
